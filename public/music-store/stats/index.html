How this is counted: first-party only, straight from the store's own server — no third-party tracker, no cookies, no personal data. A "unique visitor" is a one-way daily hash that can't identify anyone or follow them across days; no IP addresses are stored. Location is country, city and region only, looked up from the visitor's IP on this server — the IP itself is never stored. Referrers are the site name only, never the full link. Stats start the day this page went live — there is no history from before then, except the backfilled geo below, which is rebuilt from the server's access logs back to the store going live.
